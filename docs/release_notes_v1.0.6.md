# SpellCardHomework 1.0.6

> ～ 抽符 · 退治 · 收卡 ～

1.0.6 是 Pearson 全自动答题的安全性与准确率更新：把“读题 → 求解 → 填控件 → 交卷 → 判分 → 翻页”整条链路做得更稳，同时补齐公式调色板、矩阵输入和一批长期遗留问题。

## 重点更新

### 全自动更稳

- 字段级快照：每个答题控件都有 UID / signature，页面换题或控件被替换时丢弃旧答案，避免把上一小问的答案填到下一题。
- Dojo 判分状态：读取 Pearson `playerViewer` 和各控件的 `isAnswered / isCorrect`，不再只靠 DOM 文本猜对错。
- 唯一 Check：找不到 Check、找到多个 Check、Check 被禁用时停下处理，不盲点。
- 跳过入账：确实要跳过时先写入本地待人工列表，再离开；不会静默消失。
- 精确处理 Pearson 的两类“未检查就离开”警告；默认点 No，只有已经入账的跳过才允许 Yes。
- 残留反馈弹窗：识别 Dojo 已关闭但 DOM 还挂着的弹窗，自动清理，不挡下一题。

### 准确率

- 多路采样：默认 3 路独立作答，投票；分歧时追加样本，再做交叉审核和本地代入验算，必要时 R1 复核。
- 选项匹配：支持 `B`、`B. 90%`、`Option B: ...` 和完整选项文本；重复/歧义选项拒绝瞎点。
- 公式提取：从 MathML / KaTeX / LaTeX / `data-latex` / aria-label 提取公式，补进题干。
- 公式调色板：支持 More 第二页的结构模板；矩阵、向量、分段题可自动插入。
- 矩阵输入：尺寸弹窗 id 不固定时按“两个数字输入 + OK”兜底，spinner 回读，单元格逐个填入并校验。

### 交互

- 打开程序不再自动开始退治；必须手动点「开始退治」。
- 张开/关闭结界、开始/结束退治都有 Toast。
- 「关于作者」加入开发组成员「会哈气の祥」，三位开发者竖排展示。
- 版本号、启动图、安装包和文件元数据统一为 `1.0.6`。

### 修复

- `Incorrect` 被包含 `correct` 子串误判为已完成。
- 跳过题/部分正确题被“回补未完成题”反复拉回。
- 手动收工后仍弹“这一轮退治完了”。
- 填空数量不足仍去 Check。
- `CHOICE B`、`**CHOICE**: A`、`CHOICE = C` 等模型格式解析失败。
- beta 与同号正式版比较错误，beta 用户收不到正式版更新。
- 删除试用记录后可无限重领 5 天试用。
- 账本柱状图缺字体崩溃；窗口最小化导致自动监视被关闭。

## 已知限制

- 图形题、图片选项、需要额外材料（表格/打印件）的题仍可能失败，需要在待人工列表中复核。
- 部分正确题如果 Pearson 已判分且没有 Check，无法在同一题内补分，可手动重做或使用 Similar Question。
- 自动答题不能保证 100% 正确；请在最终提交前自行复核。
