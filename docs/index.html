三道境界

抽符 · 识题

按 F8 截下题目，魔理沙会把文字、公式、选项一起抄进摘录。英文题自动交给慧音翻译。

退治 · 作答

灵梦带着你的模型出场：选择题、填空题、下拉框、多小问，逐题给出答案。

收卡 · 收尾

答案收进灵梦的答案栏，一键誊抄；网页作业还能自动填、自动交、自动翻页。

札

符卡一览

六张常用符卡，覆盖从识题到交卷的全流程

截屏识别

全屏、窗口、框选三种抽符方式，本地 OCR 与视觉模型双保险。

公式渲染

LaTeX 自动转成 √、x²、≤、∑、矩阵等可读符号，不再看天书。

英文翻译

识别到英文题目时，慧音会先译成中文，再交给式神作答。

全自动网页答题

CDP 接管 Edge / Chrome，单选、多选、填空、下拉、多小问全都能填。

香火钱账本

每次调用的 tokens、耗时、费用估算都记在账上，30 天柱状图一目了然。

一机一码

Ed25519 签名授权，首次启动可试用五天；激活码绑定本机灵符。
