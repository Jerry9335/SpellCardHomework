# SpellCardHomework 1.0.6-rc.03

> ～ 抽符 · 退治 · 收卡 ～

1.0.6-rc.03 是 1.0.6 的发布候选版本，重点补齐首次安装与新手上路体验，并把程序、安装器、启动图和文档的版本标记统一到 `1.0.6-rc.03`。

## 重点更新

### 首次安装 · 结界契约

- 激活授权后进入 3 页契约向导：
  1. 选择结界来源（模型提供商，支持 DeepSeek / OpenAI / 硅基流动 / OpenRouter / 阿里云百炼 / 本地 Ollama 等）；
  2. 填写并测试 API Key，也可直接跳过，或打开对应提供商的申请页；
  3. 选择主模型与视觉模型；视觉模型可留空，稍后在设置里补。
- 契约完成或跳过都会进入新手引导；关闭窗口会保留断点，下次启动可以继续。
- 修复：同一 Windows 用户重装时，如果目录里残留旧 `config.json`，首次激活后仍会进入结界契约与新手引导。
- 修复：旧版误写成 `legacy`、或授权已恢复但从未配置过 API Key/自定义接口的用户，新版会自动补走契约，不再直接进主界面。
- 修复：展开「更多提供商」时来源卡片会挤出窗口；第一页内容改为可滚动，底部「之后就配 / 就借这家」始终可见。
- 修复：从开始菜单等非安装目录启动时，契约页与新手引导的角色头像不显示；现在使用程序自身 assets 的绝对路径。
- 修复：标题字体因「华文行楷」缺少“麗/郷/題”等字而逐字回退成黑体；标题统一改用字形完整的楷体。
- 修复：点“之后再配”会直接结束契约流程；现在正确进入第 2 签。
- 修复：契约窗口按 Windows 工作区居中；首次安装时主界面先隐藏，契约阶段只显示契约窗口，避免 VM 上被主窗口挡住或底部被任务栏裁切。
- 修复：契约窗口创建后强制 `lift/focus` 并短暂置顶，引导窗口异常时回主界面而不是像程序退出。

### 六步新手引导

- 由蓬莱山辉夜、八意永琳、铃仙、因幡天为、因幡天为、今泉影狼逐页带路：
  1. 主界面与三张符；
  2. 出题 / 摘录；
  3. 张开结界与连接答题浏览器；
  4. 开始退治与全自动答题；
  5. 香火钱账本；
  6. 设置与再次引路。
- 引导采用主界面实景 + 聚光灯高亮 + 右侧角色卡，最后点「开始使用」进入主界面。

### 老用户与重看

- 通过 `onboarding_state` 区分首次安装、升级用户和已完成用户；升级用户不会重复弹出契约/引导。
- 设置底部新增「引路与契约」：
  - 「重看新手引导」随时可重走六步，不会重置 API Key、模型或账本；
  - 「继续契约」只在契约尚未完成时出现，可从断点继续。

### 版本与界面

- 程序、安装器、MSIX、README、官网、安装说明和启动图统一为 `1.0.6-rc.03`。
- 关于作者继续保留三位开发者竖排：Shinichi、Fastrof、会哈气の祥。
- 设置窗口高度与滚动区域调整，底部保存按钮不再被任务栏遮挡。

## 已知限制

- 这是发布候选（RC）版本，仍建议在真实作业中先小范围试用。
- 图形题、图片选项、需要额外材料（表格/打印件）的题仍可能失败，需要在待人工列表中复核。
- 部分正确题如果 Pearson 已判分且没有 Check，无法在同一题内补分，可手动重做或使用 Similar Question。
- 自动答题不能保证 100% 正确；请在最终提交前自行复核。

## 升级说明

- 本版本与 1.0.5 / 1.0.6 使用同一安装标识，安装会覆盖升级；授权、设置和 API Key 会保留。
- 升级前建议关闭正在运行的旧版本。
- 卸载会按设计清除本机授权与试用记录，设置与 API Key 保留。
