## 2. 顶部横幅（Banner）

- **比例**：6:1（程序会按高度居中裁切，宽幅更好看）
- **分辨率**：**1920 × 320**
- **放置**：`assets/banner.png`
- **构图**：横向风景，主体放在画面垂直中线附近；不要放脸（会被裁成细条）

**中文提示词：**


## 5. 生成参数建议

| 项目 | 建议 |
|---|---|
| 采样器 | Euler a / DPM++ 2M Karras |
| 步数 | 28～35 |
| CFG | 6～8 |
| 高分辨率修复 | 开启，放大 1.5～2 倍 |
| 头像背景 | 纯色或透明（方便圆形裁切） |
| 一致性 | 固定 seed，或使用同一 LoRA 保持画风统一 |

## 6. 生成后怎么放进程序

1. 启动图存为 `assets/splash.png`（1536×960）
2. 横幅存为 `assets/banner.png`（1920×320）
3. 8 个头像按上表 key 命名，存到 `assets/char/fan/avatar_<key>.png`
   - 程序会自动缩放成 64px 并裁成圆形，原图 1024×1024 即可
4. 图标存 `assets/icon.png`，运行 `python tools/make_assets.py` 生成 `.ico`
5. 在 `CREDITS.md` 里写明：AI 生成、使用的工具与模型、是否可商用

> 如果头像背景不是纯色，程序裁圆时边缘会带背景；建议生成时选纯色背景，或让我帮你做去背/圆形裁切。
