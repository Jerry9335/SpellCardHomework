安装与首次启动

四步进入结界

  1. 运行安装包
    双击 Setup，选择「仅为我安装」即可，不需要管理员权限。
  2. 同意许可协议
    阅读后选「我同意此协议」，下一步继续。
  3. 首次启动
    会先弹出「博麗神社 · 结界许可」。
  1. 试用或激活
    点「先试用 5 天」直接进入；或复制本机灵符申请激活码。
  2. 填写接口
    在设置里填 Base URL 与通行密钥（API Key），点「刷新」拉模型列表。
  3. 开始退治
    按 F8 截屏识别，或打开浏览器用「张开结界 + 开始退治」。

怎么拿激活码

首次启动的授权窗口里，金色大字就是「本机灵符」（机器码），点旁边的「收下灵符」即可复制。

把机器码发邮件给下面任意一位，收到「许可咒文」（激活码）后粘贴、点「解开结界」。

试用与到期

第一次点「先试用 5 天」才开始计时，五天到期后必须激活才能进入主界面。

  • 激活码绑定机器码，换电脑或重装系统需要重新申请
  • 卸载会清除授权记录
  • 1.0.1 之前的旧短码已作废
  • 把系统时间往回调会被判为异常，试用直接作废

問

常见问题

Windows 提示「已保护你的电脑」怎么办？

安装包没有购买代码签名证书，SmartScreen 会提示。点「更多信息 → 仍要运行」即可。校验和可以在上方复制核对。

重装后为什么还是已激活？

1.0.1 起卸载会自动清除授权与试用记录。如果是旧版本卸载的，旧卸载程序不会清，需要手动删除 %APPDATA%\SpellCardHomework\license.json、trial.json、%LOCALAPPDATA%\SpellCardHomework\.spellcard_trial 和注册表里的 HKCU\Software\Shinichi\SpellCardHomework。

首次启动直接进了主界面？

先确认「关于程序」里版本是 v1.0.1，再看 %APPDATA%\SpellCardHomework\boot.log 里的 access= 记录，能看出它读到了什么授权状态。

换电脑了怎么办？

机器码会变，需要把新的「本机灵符」发邮件重新申请激活码。旧码只对旧机器有效。

会自动上传我的数据吗？

不会。API Key 用 Windows DPAPI 加密保存在本机，用量记录也只写在本机文件里，不会上传到作者服务器。
