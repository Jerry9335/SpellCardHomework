# SpellCardHomework 1.0.6-rc.04

> ～ 抽符 · 退治 · 收卡 ～

1.0.6-rc.04 是 1.0.6 的发布候选版本，重点调整更新机制，并继续打磨首次安装与新手引导体验。

## 重点更新

### 更新检查

- **首次安装 / 首次启动不检查更新**，首次契约与新手引导流程不会被更新提示打断。
- 之后**每次启动只检查一次**，不再每 30 分钟轮询。
- 发现新版本时只弹提示，按钮为：
  - **前往下载页**
  - **复制链接**
  - **稍后再说**
- **不会自动下载、自动安装或自动退出**；下载与安装由用户亲自完成。
- 「稍后再说」不会记住跳过，**下次启动继续提示**。
- 设置页移除自动检查开关、检查间隔、封笔与下载线程，只保留渠道、上次检查与「立即打听」。

### 首次安装与重装

- 保留 3 页「结界契约」与 6 步新手引导。
- 修复卸载后重装仍把旧 `config.json` 当老用户的问题：使用安装目录锚点识别重装，自动重置首启/引导状态，同时保留 API Key、模型和账本。
- 修复契约页被主界面遮挡的问题；首次安装阶段先隐藏主界面，只显示契约窗口。
- 修复点「之后再配」会退出契约的问题，现在正确进入第 2 签。

### 界面与资源

- 展开「更多提供商」后，来源列表可滚动，底部按钮始终可见。
- 修复从开始菜单或非安装目录启动时契约页/新手引导头像不显示的问题。
- 修复标题字体因缺字逐字回退、出现半行楷半黑体的问题，标题统一为楷体。
- 关于作者中第三位「会哈气の祥」的头像改为与另外两位一致的圆形金边规格。
- 程序、安装器、MSIX、README、官网、安装说明和启动图统一为 `1.0.6-rc.04`。

### 保留的答题能力

- 字段级快照（UID / signature）、Dojo 判分状态、唯一 Check、跳过入账、精确离开警告。
- 多路采样 + 投票 + 分歧追加 + 交叉审核 + 本地验算 + R1 复核。
- 选项匹配、公式调色板 More 第二页、矩阵/向量/分段模板、反馈状态机。
- 手动开始退治、结界开关 Toast、香火钱账本等。

## 已知限制

- 这是发布候选（RC）版本，建议先在真实作业中小范围试用。
- 图形题、图片选项、需要额外材料（表格/打印件）的题仍可能失败，需要在待人工列表中复核。
- 部分正确题如果 Pearson 已判分且没有 Check，无法在同一题内补分，可手动重做或使用 Similar Question。
- 自动答题不能保证 100% 正确；请在最终提交前自行复核。

## 升级说明

- 本版本与 1.0.5 / 1.0.6 / 1.0.6-rc.03 使用同一安装标识，安装会覆盖升级；授权、设置和 API Key 会保留。
- 升级前建议关闭正在运行的旧版本。
- 卸载会按设计清除本机授权与试用记录，设置与 API Key 保留。
