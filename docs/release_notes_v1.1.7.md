# 符卡作业簿 1.1.7（2026-11-28）

> ～ 抽符 · 退治 · 收卡 ～

## 一、自动答题修复（本版最重要）

这一版先修自动答题的完成率，再谈界面。

- **多小问不再提前跳题**：`part_n < part_m` 时只允许翻下一小问；第 5 题的 8 个小问从 `[1,8]` 一直做到 `[8,8]` 才离开，已实测。
- **多小问上下文补全**：从 第 2 小问 起把整题已知条件一起交给模型。第 8 题 第 2 小问 原来缺 `lim f=5 / lim g=10`，只能回 `->`；补全后正确得到 `1/2`。
- **不要化简**：题目明确要求不化简时保留 `5/10`，不再被自动约成 `1/2`。
- **∞ 使用调色板真符号**：键盘输入的 `\inf` 会被 答题平台 当字面 `infinity`；现在点公式调色板的 ∞ 按钮插入真符号，第 17 题 实测 Correct。
- **失败不再自动跳题**：单小问/最后一小问失败时停在当前题重试，不再记一笔就跳下一题。
- **采样截断兜底**：三路流式采样连续失败时，追加单路非流式请求，减少因 SSE 截断直接判死。
- **实机结果**：B6-Chapter 11.1 全 20 题 Correct，**作业得分 100%，20/20 points**。

> 自动答题仍不能保证新题 100%；这里记录的是本版修复点和已跑通的实机题集。

## 二、设置中心重构

- 新「博麗神社 · 境界設定」：左侧六分区 + 卷轴卡片。
- 结界契约（模型与 API）、读符术式（读图与截图）、退治术式（自动答题）、绘卷外观（主题与通知）、香火钱（用量与费用）、神社登记（授权与版本）。
- 东方名 + 白话副标题；小屏滚动、未保存提示、保存失败提示、参数格式/端口/温度校验。
- 测试连接、拉模型、查余额、打开账本、查看许可、复制机器码、重看引路、立即打听、测试通知、更新说明、关于程序均已接通。

## 三、主窗口与账本

- 主窗口默认放大为 `1660×987` 宽长方形，三栏标题和誊抄/抹去按钮不再被挤压。
- 状态栏“文文”号外播报修正为 `aya` 头像；旧版会沿用上一位的八云紫头像。
- 设置中心 `1200×780`，账本 `1240×1000`。
- 香火钱账本：日期/式神/搜索筛选、表头排序、双击详情、导出筛选结果、清空确认。
- 柱状图/折线图可切换，并记住上次类型；每次打开账本都播放一次走势动画：折线沿数据点生长，柱形从基线长起。
- 底部说明、状态、倒空赛钱箱、关上账本固定可见。

## 四、首次引导、单实例与更新说明

- 结界契约与新手引导均为全屏无边框；契约完成后 `0 毫秒` 接全屏引导。
- 契约取消回主界面，不再退出程序；中断后不自动反复弹，用户去设置补。
- 引导关闭/跳过都结束，不再保留半截续跑；设置中心提供「重看引路」。
- 全新安装的试用期改为 **3 天**；激活窗口的按钮改为「先试用 3 天进入」，关闭窗口也走试用启动，不再误退出。
- 试用剩 1 天 / 最后几小时时，启动后自动弹 Windows Toast 提醒（同一天不重复）。
- 单实例：第二次启动聚焦已有窗口后退出。
- 新增全屏「更新说明 · 新版绘卷」；新装/重装会在契约与引导结束后展示，按版本记录已读；设置中心「神社登记 → 关于 → 更新说明」可随时重看。
- 新用户首次安装、卸载重装：契约与引路完成后才展示本版更新说明；不再在启动时提前标记已读。
- 更新检查：首次安装/重装的首次启动不检查，下一次启动恢复自动检查；有新版本和无新版本都会弹 Toast（自动检查也通知）。
- 更新弹窗恢复「让文文去取 / 打开号外页 / 晚点再说 / 封笔到…」四个入口；下载走多线程、断点续传和 SHA256，校验后由更新助手安装。
- 设置中心恢复「自动打听 / 报信间隔 / 封笔到 / 最多分片」；自动检查会遵守开关、间隔和封笔，手动立即打听不受影响。
- 状态栏「文文」号外播报改用 `aya` 头像，不再沿用上一位角色。

## 五、授权与密钥安全

- 契约页不再回显已保存的完整 API Key；旧密钥留空保留，输入新密钥会替换。
- 契约页提供「清除已存」按钮，可主动删除旧密钥。
- 卸载程序现在会清理 `%APPDATA%\SpellCardHomework` 与 `%LOCALAPPDATA%\SpellCardHomework`，包括 config、API Key、账本与日志。
- 源码与安装包中没有硬编码 API Key。
