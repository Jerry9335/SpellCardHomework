## 一、目标与范围

本方案包含四块：

| 模块 | 一句话 |
|---|---|
| 自动检查更新 | 文文定期去打听新版本，用户可选渠道、频率，可「封笔」到某天 |
| 完整 Windows Toast | 更新、试用到期、余额、退治收工等事件，统一走式神传讯 |
| 小日历 | 自绘月历，用来选「封笔到哪天」 |
| 试用到期提醒 | 剩余 3 天 / 1 天 / 当天各提醒一次，Toast + 主界面同步 |

**不在本方案内**：自动下载安装、遥测、云同步、多语言。

## 四、自动检查更新

### 4.1 流程

```
启动 5 秒后
  → 读配置：开关 / 渠道 / 间隔 / 封笔日期
  → 若封笔未到期 → 跳过（手动检查仍可用）
  → 若距上次检查 < 间隔 → 跳过
  → 后台线程请求 Gitee / GitHub
  → 解析版本号，和 settings.APP_VERSION 比较
  → 有新版：写 update_last_check，弹「号外」窗口 + Toast
  → 无新版：静默，只更新 update_last_check
  → 请求失败：静默，写 update.log，到下次间隔再试
```

### 4.2 渠道

设置项：**报信路线**

| 选项 | 行为 | 旁注 |
|---|---|---|
| 自动（推荐） | 先问 Gitee，失败再问 GitHub；两边都有取版本高的 | 国内先问人间之里，问不到再去外界 |
| 仅 Gitee | 只问 Gitee | 快，但可能没有 Release 附件 |
| 仅 GitHub | 只问 GitHub | 主仓库，国内可能慢 |

接口：

- Gitee：`https://gitee.com/api/v5/repos/jerry6663/SpellCardHomework/releases/latest`
- GitHub：`https://api.github.com/repos/Jerry9335/SpellCardHomework/releases/latest`

字段：`tag_name`、`name`、`body`、`created_at` / `published_at`、`html_url`、`assets[].browser_download_url`。

### 4.3 频率

设置项：**报信间隔**

| 选项 | 值 |
|---|---|
| 每次启动 | `0` |
| 每 5 小时 | `5` |
| 每天 | `24` |
| 每三天 | `72` |
| 每周 | `168` |
| 自定义 | 输入 1–720 小时 |

默认：**每 5 小时**。
判断：`now - update_last_check >= interval * 3600`（`0` 时只要本次启动没查过就查）。

### 4.4 封笔（暂停更新）

设置项：**封笔到**

- 显示当前状态：`未封笔` / `封笔到 2026-12-01（还剩 9 天）`
- 按钮：`选日子` → 打开小日历
- 快捷：`歇 1 天`、`歇 3 天`、`歇 7 天`、`歇 30 天`
- 封笔期间：**不自动检查**；`立即打听` 按钮仍然可用
- 到期当天 00:00 后恢复；恢复后立即检查一次
- 存储：`update_snooze_until` = 所选日期 23:59:59 的时间戳

### 4.5 「号外」窗口

标题：`博麗神社 · 号外`

内容：

```
文文：新号外印好了——

v1.0.2 → v1.0.3
发布日期：2026-11-30
来源：Gitee / GitHub

【更新内容】
（Release 说明纯文本，最多 12 行，超出可滚动）

[去取新符]  [晚点再说]  [封笔到…]
```

- `去取新符`：打开下载页（优先 Release 附件，没有就打开 release 页面）
- `晚点再说`：关闭，本次启动不再提示
- `封笔到…`：打开小日历，选完关闭窗口
- 不做自动下载、不自动安装

### 4.6 失败与边界

| 情况 | 处理 |
|---|---|
| 网络超时 / 被墙 | 静默，写 `update.log`，下次再试 |
| 401/403/429 | 静默，记录状态码 |
| Gitee 没有 Release | 自动渠道回退 GitHub |
| 两边版本不同 | 自动渠道取**更高**的；同版本优先 Gitee |
| 本地版本更高（开发版） | 不提示 |
| 预发布 `-beta` | 不提示 |
| 用户正在全自动退治 | 只更新状态栏，不弹窗打断；Toast 照常 |

### 4.7 配置字段

```json
{
  "update_enabled": true,
  "update_channel": "auto",
  "update_interval_hours": 24,
  "update_last_check": 0,
  "update_snooze_until": 0,
  "update_repo": "Jerry9335/SpellCardHomework",
  "update_gitee_repo": "jerry6663/SpellCardHomework",
  "update_last_version": ""
}
```

## 六、小日历

### 6.1 外观

```
┌─────────────────────────────┐
│  封笔日历              ×   │
│  ‹   2026 年 12 月   ›      │
│  一  二  三  四  五  六  日 │
│  …  …  …  …  …  …  …       │
│  …  …  …  [1] …  …  …       │
│                             │
│  歇 1 天  歇 3 天  歇 7 天  │
│  歇 30 天                    │
│                             │
│  灵梦：让文文歇到 12 月 1 日？│
│           [算了]  [就这天]   │
└─────────────────────────────┘
```

### 6.2 规则

- 自绘 Tkinter 月历，不引入第三方库
- 周一为每周第一天
- 今天之前不可选（灰掉）
- 可选范围：今天 ~ 今天 + 365 天
- `‹` `›` 切换月份，不能翻到本月之前
- 点日期 → 高亮 + 底部文案更新
- `Esc` 关闭，`Enter` 确认
- 确认后写入 `update_snooze_until`

### 6.3 话术

- 标题：`封笔日历`
- 副标题：`让文文歇到哪天？`
- 确认：`就这天`
- 取消：`算了`
- 选中后：`灵梦：行吧，让文文歇到 12 月 1 日。别到时候又忘了。`

## 七、试用到期提醒

### 7.1 触发点

`license.trial_status()` 返回 `days_left`：

| 剩余天数 | 提醒 | 去重键 |
|---|---|---|
| 3 | Toast + 主界面状态栏 | `trial:YYYY-MM-DD:3` |
| 1 | Toast + 主界面状态栏 | `trial:YYYY-MM-DD:1` |
| 0 / 已过期 | 只走激活窗口，不弹 Toast | — |

- 只在**当天第一次启动**触发
- 提醒后写入 `toast_seen` 和 `trial_reminded`
- 已激活（licensed）→ 不再提醒，清空记录
- 重新试用 / 计时被篡改 → 沿用现有 `check_access()` 判定，不新增逻辑

### 7.2 主界面状态

主界面标题栏或状态栏显示：

- 剩 3 天：`结界余 3 日`
- 剩 1 天：`结界余 1 日 · 速去登记`
- 已过期：`结界已散 · 去登记`

| 场景 | 文案 |

自动答题 Toast 规则：

- 一轮 = 一次「开始退治」到结束
- 正常做完：`魔理沙：这一轮退治完了。对 X 错 Y。`
- 因答错/卡住/模型失败结束：`魔理沙：啧，这一轮没退治干净……对 X 错 Y，你自己看着办。`
- 用户主动点「收工」：不弹
- 每轮最多一条，不按题刷屏
